# ProHW Homepage – Vorlage

Diese Vorlage liegt bewusst im Branch `prohw-vorlage` und verändert die live geschaltete HMZ-Seite nicht.

## Enthalten
- responsive Startseite im Stil der HMZ-Seite, aber eigenständiges ProHW-Design
- Leistungsbereiche: Raumgestaltung, Bodenbeläge, Trockenbau, Montagearbeiten, Reparaturservice, Fachhandwerkervermittlung
- Kontaktangaben Pro HW GmbH
- SEO-Basisdaten und Canonical für `https://www.prohw.de/`
- Hinweisbereich für die abschließende rechtliche Prüfung

## Vor Livegang noch nötig
- endgültiges Logo/Firmenfarben bestätigen
- reale Fotos oder freigegebene Projektbilder einbauen
- Impressum und Datenschutz erstellen bzw. prüfen
- Domain `prohw.de` auf das spätere Hosting/GitHub Pages umstellen
- SSL und Weiterleitung `www`/ohne `www` testen
